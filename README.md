# Luis Dev - Agencia de Desarrollo Web

Bienvenido al repositorio oficial de **Luis Dev**, una agencia de desarrollo web moderna enfocada en brindar presencia digital a profesionales independientes, empresas y restaurantes.

## 🚀 Tecnologías Utilizadas

- **Frontend**: HTML5, CSS3 (Custom Styles), Bootstrap 5, JavaScript (ES6+).
- **Backend**: Node.js, Express.js.
- **Herramientas**: Nodemailer (Notificaciones por correo), Dotenv (Gestión de variables de entorno).
- **Animaciones**: AOS (Animate On Scroll).

## ✨ Características Principales

- **Diseño Premium**: Interfaz moderna con efectos de Glassmorphism.
- **Totalmente Responsivo**: Optimizado para dispositivos móviles, tablets y escritorio.
- **Formulario de Contacto Real**: Los mensajes se reciben directamente por correo electrónico.
- **Integración Directa**: Botones de contacto rápido vía WhatsApp.

## 🛠️ Instalación y Configuración

1. **Clonar el repositorio**:
   ```bash
   git clone [url-del-repo]
   cd agencia-web-luis
   ```

2. **Instalar dependencias**:
   ```bash
   npm install
   ```

3. **Configurar Variables de Entorno**:
   Crea un archivo `.env` basado en el archivo `.env.example`:
   ```env
   EMAIL_USER=tu-correo@gmail.com
   EMAIL_PASS=tu-contraseña-de-aplicacion
   PORT=3000
   ```

4. **Iniciar el Servidor**:
   ```bash
   npm start
   ```
